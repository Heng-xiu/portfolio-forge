02 / DIFFERENCE

The Craft三個決定質感、原文四步法沒教的環節

防幻覺
一般做法AI 邊做邊編，經歷跟連結都靠猜。
先寫 CONTENT.md 當唯一真值，參考圖裡的亂字一律以文檔為準。
審美把關
一般做法參考圖生完就直接拿去複刻。
對抗式逐張評審：字級、呼吸感、構圖套路、幻覺文字、跨圖一致性，不過關就單張重生。這是靈魂。
上線驗收
一般做法build 成功就當作交付。
headless 逐段截圖對照參考圖比對；部署後 smoke test，且不碰使用者既有網域。
03 / PIPELINE

Six Stages從一句話定位，到上線

0

定位訪談

用結構化提問收斂：網站給誰看、視覺風格、語言規模、素材來源。

1

內容文檔

把 profile、定位、色盤、section 結構寫成 CONTENT.md ——後續一切的唯一真值。

2

生成參考圖

用 taste-skill 的 imagegen-frontend-web，一個 section 一張高審美參考圖。

3

對抗式評審 靈魂

逐張挑戰、不過關就單張重生。這一步決定成品是「像模像樣」還是「真的好看」。

4

高保真複刻

把定稿參考圖 + 內容文檔 + 真實素材交給 Codex Frontend App Builder，1:1 還原。

5

逐段 QA

puppeteer 真實捲動、逐 section 截圖，對照參考圖驗收。不到位就退回迭代。

6

可逆部署

Cloudflare Pages 上獨立網址 → 線上 smoke test → 網域決策交還你。
